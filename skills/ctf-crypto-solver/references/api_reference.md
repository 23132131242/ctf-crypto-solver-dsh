# Crypto 分支索引

按 SKILL.md 中的体系识别结果，打开同目录下对应参考文件：

- `public-key.md`：RSA、ECC、签名、格与后量子难题。
- `symmetric-random-protocol.md`：对称加密、随机数、密码协议、区块链签名、零知识。
- `hash-math-classical.md`：哈希、有限域、秘密分享、古典与自定义算法。

复现记录的基本格式：输入及进制/哈希 → 假设及公式 → 命令和版本 → 原始输出 → 独立验证 → 结论或失败原因。所有高级攻击均是根据条件选用的知识路线，不表示插件自带依赖或可自动解决所有实例。
